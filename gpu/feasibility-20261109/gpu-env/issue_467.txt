--- COMMENT by Officeyutong 2025-10-20T15:12:54Z
Hooks we need:
- Shared memory initialization.
- Initialization of `bpf_attach_ctx`
- Instatiation of each handler in `instantiate_handler_at`
- Initialization of `syscall_context`

Callbacks can be provided by each attach implementation. The creation of a `bpf_attach_ctx` doesn't rely on shared memory, so call to bpf_attach_ctx at agent side would be:
- Create a bpf_attach_ctx
- Register attach implementations
- Initialize global shared memory. Call callbacks related to initialization of shared memory registered by each attach implementation.
- When called `bpf_attach_ctx::init_attach_ctx_from_handlers`, call callbacks `Initialization of bpf_attach_ctx` of all attach implementations
- During the instantiating of each handler, call callbacks of each attach implemantations, providing the handler to the callback. 

For the syscall server side, since we won't call bpf_attach_ctx, so the following way applies:
- Syscall server provide a function to register callbacks for initialization of syscall server
- Each attach implementation provide a `__attribute__((constructor))` function, in it attach implementation use `dlsym` to lookup the register function provided by syscall server, registering its callback
- For nv_attach_impl, it will register a function to call `cuInit`
