## Summary

- enumerate CUDA devices and retain each device SM architecture and module cache
- load and resolve patched PTX, kernels, globals, and cache entries within the active device context
- lazily load the current-device module on its first intercepted launch and fall back to the original CUDA path on failure
- expose the device ordinal to GPU probes and reject invalid ordinals
- preserve CUDA 12/13 and single-GPU compatibility
- add focused device-manager, compiler-failure, and helper-registration coverage plus a minimal per-device launch-count example
