BODY:
Add automatic PTX version upgrade based on target SM architecture:
- sm_120+ (Blackwell): PTX 8.7
- sm_100+ (Blackwell): PTX 8.5
- Older architectures: keep original version

This enables support for Blackwell GPUs (sm_120) while maintaining backward compatibility with older CUDA toolkits and GPU architectures.

Also refactored rewrite_ptx_target() to be shared between nv_attach_utils.cpp and nv_attach_fatbin_record.cpp.
