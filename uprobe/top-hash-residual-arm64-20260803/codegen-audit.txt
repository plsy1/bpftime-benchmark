Interpretation:
- The source-level helper is the same, but the final machine-code boundary is
  not byte-identical across the standalone diagnostic executable and agent DSO.
- Runtime LTO/constant propagation shapes the final links differently.  The
  agent helper is a small wrapper/tail-call into const-propagated functions;
  the standalone symbol contains a much larger generic body.
- Symbol size does not by itself predict runtime cost.  It proves only that a
  subtraction across these final binaries is not an exact code-identical A/B.
