# Official no-BTF uprobe benchmark on Jetson ARM64

This directory archives a complete run of the repository's official
`benchmark/uprobe/benchmark.py` suite on Jetson Orin Nano.

## Run identity

- Source branch: `codex/official-no-btf`
- Source commit: `1a1dc0d6c2026a5e4b0e4faa964e3eea8ccdd241`
- Iterations: 10 per benchmark mode
- Modes: kernel uprobe, BPFtime userspace uprobe, embedded LLVM VM
- Start: 2026-09-09 15:29 JST
- Completion: 2026-09-09 17:03 JST
- Total duration: 5654.29 seconds
- Completion status: success

The system had no readable `/sys/kernel/btf/vmlinux`. The benchmark ran in
the 25 W power mode with `jetson_clocks` enabled. CPU, GPU, and EMC frequencies
were pinned to the maximum frequencies permitted by that power mode.

## Key results

| Operation | Kernel avg (ns) | BPFtime avg (ns) | Kernel/BPFtime |
|---|---:|---:|---:|
| uprobe | 1545.80 | 470.30 | 3.29x |
| uretprobe | 2081.20 | 467.41 | 4.45x |
| uprobe + uretprobe | 2230.11 | 540.94 | 4.12x |

The embedded LLVM VM average was 242.37 ns. Full map and probe statistics are
in `results.md` and the machine-readable raw samples are in
`benchmark-output.json`.

## Files

- `benchmark-output.json`: all raw values and computed statistics.
- `results.md`: report generated by the benchmark runner.
- `benchmark-logs.txt`: application-level benchmark log.
- `tmux-benchmark.log`: complete captured tmux output, including libbpf output.
- `environment.txt`: source, OS, toolchain, and frequency configuration.

## Reproduction

From the source tree:

```bash
sudo jetson_clocks
sudo env \
  BPFTIME_VM_NAME=llvm \
  LD_LIBRARY_PATH=/usr/lib/llvm-16/lib \
  PATH=/usr/lib/llvm-16/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin \
  python3 -u benchmark/uprobe/benchmark.py --iter 10
```
